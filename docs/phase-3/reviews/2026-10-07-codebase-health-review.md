# Codebase health review — 7 October 2026

> 📌 **Doc status: HISTORICAL** — dated assessment after the fixes below. Source references are pinned to the reviewed commit. The [architecture remediation](../progress/2026-10-07-architecture-remediation.md) records subsequent delivery; functional bugs and UX decisions remain open.

The core architecture is sound: document sessions, revision/raw-baseline conflict protection, one measured print plan, a shared renderer, and semantic reading are useful boundaries. Automated coverage is substantial. The principal debt is reliability at storage/input boundaries, retained obsolete implementations, and an authoring UI that exposes too many controls. Broad release still needs the existing device, participant and physical-print acceptance work.

## Architecture and maintenance decisions

- **Retire the old implementation deliberately.** Legacy canvas/cards/chips, drag state, popovers/forms, confirmation dialogs and pagination helpers have no current runtime path after the startup fix. Their tests and comments still describe replaced behavior. Keep the live pointer-threshold helper. Start at [InstructionCanvas.tsx:1](https://github.com/P-Leidel/instruction_builder_v2/blob/3a4b67acf7f246419053c7d7f02ff1b45f196c43/src/components/InstructionCanvas/InstructionCanvas.tsx#L1), [canvas.ts:70](https://github.com/P-Leidel/instruction_builder_v2/blob/3a4b67acf7f246419053c7d7f02ff1b45f196c43/src/state/canvas.ts#L70), [pdf-pagination.ts:1](https://github.com/P-Leidel/instruction_builder_v2/blob/3a4b67acf7f246419053c7d7f02ff1b45f196c43/src/lib/pdf-pagination.ts#L1). Shared old CSS forces new overrides: [global.css:504](https://github.com/P-Leidel/instruction_builder_v2/blob/3a4b67acf7f246419053c7d7f02ff1b45f196c43/src/styles/global.css#L504), [editor.css:101](https://github.com/P-Leidel/instruction_builder_v2/blob/3a4b67acf7f246419053c7d7f02ff1b45f196c43/src/components/InstructionEditor/editor.css#L101).
- **Narrow storage transactions.** Every operation reads all keys/values, including tombstones and recovery copies. This makes each autosave/preference write grow with total retained data. Use keyed reads and list cursors while preserving atomic revision/recovery checks. The code path is confirmed; practical slowdown is unbenchmarked. [guide-repository.ts:29](https://github.com/P-Leidel/instruction_builder_v2/blob/3a4b67acf7f246419053c7d7f02ff1b45f196c43/src/lib/guide-repository.ts#L29), [guide-repository.ts:34](https://github.com/P-Leidel/instruction_builder_v2/blob/3a4b67acf7f246419053c7d7f02ff1b45f196c43/src/lib/guide-repository.ts#L34).
- **Make verification ownership clearer.** CI browser tests depend on hidden `.claude/skills` scripts that ordinary lint excludes. Move maintained test drivers/helpers into an explicit test directory and lint them. [check-browser.mjs:30](https://github.com/P-Leidel/instruction_builder_v2/blob/3a4b67acf7f246419053c7d7f02ff1b45f196c43/scripts/check-browser.mjs#L30), [eslint.config.js:9](https://github.com/P-Leidel/instruction_builder_v2/blob/3a4b67acf7f246419053c7d7f02ff1b45f196c43/eslint.config.js#L9).
